Start

Band-Konfigurationen: Typ, Endpunkt und History kombinieren. Pro Label ist genau eine Konfiguration aktiv (Punkt links).

Endpunkte

SageMaker-Endpunkte, wiederverwendbar für mehrere Konfigurationen auf der Start-Seite.

History-Presets

Benannte Listen von Video-IDs, je eine pro Zeile — nutzbar als History bei beliebigen Endpunkten.

Seitentypen

Welche Seitentypen es auf zdf.de gibt und woran man sie erkennt. JSON-Templates lassen sich einem Typ zuordnen — das Popup zeigt dann nur passende Templates für die aktuelle Seite.

JSON-Templates

GraphQL-Queries, abrufbar per Rechtsklick auf das Extension-Icon. Variable $canonical wird automatisch aus der aktuellen Seiten-URL gefüllt (letztes Pfadsegment).

Query-Referenz

Bekannte Felder je Seitentyp zum Copy-Paste in eine neue Query.

A/B-Gruppe

Verfügbare A/B-Testgruppen von abgroup.zdf.de/test.json. Gesetzt wird die Gruppe direkt im Popup auf zdf.de (schreibt local-user-data im localStorage und lädt neu) — hier lässt sich nur die Liste aktualisieren.

Quick Search

Spotlight-artiges Such-Overlay auf zdf.de statt der /suche-Seite. Änderungen greifen sofort, auch auf schon offenen Tabs.
